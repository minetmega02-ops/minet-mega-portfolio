# Minet Mega Portfolio

This imported project is a static HTML/CSS website. Keep the existing files and structure in `Minet_Mega_Portfolio/`.

## Run on Replit

Use the **Start application** workflow (the Run button). It runs:

```sh
python3 -m http.server 5000 --bind 0.0.0.0 --directory Minet_Mega_Portfolio
```

Open the preview to view the homepage. The Family, Academics, and Skills pages are linked in the navigation.

No third-party packages, secrets, database, or build step are required. Python's built-in server is used for development preview, not production hosting.

Edit the HTML pages or `style.css`, then refresh the preview to see changes. The stylesheet loads Poppins from Google Fonts, requiring an internet connection; otherwise the browser uses its sans-serif fallback.
